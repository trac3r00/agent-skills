# Security policy

## Reporting a vulnerability

Do not open a public issue for a credential leak, command-injection path,
unsafe file operation, or a workflow that could cause data loss. Report it
privately through the repository owner's GitHub security contact with concise
reproduction steps and impact. Never include secrets or live account data.

## Supported version

Security fixes are applied to the latest `main` revision. Consumers should
update to the latest commit or tagged release before reporting a suspected
issue.
